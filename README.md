# Carnet du Héros — V0.3

Refonte visuelle inspirée d'un grimoire moderne : bibliothèque d'aventures, feuille d'aventure, inventaire par catégories, combat, notes et éditeur de feuille.

## Déploiement Vercel

1. Remplacer les fichiers du dépôt GitHub par ceux de ce ZIP.
2. Vérifier que `package.json` indique bien `next: 15.5.9`.
3. Commit les changements.
4. Vercel redéploie automatiquement.

## Lancer localement

```bash
npm install
npm run dev
```
